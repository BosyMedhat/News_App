📰 News App – Real-time News Reader

News App is a modern mobile application built using Flutter, designed to provide users with the latest daily news across various categories with a clean and interactive UI.

The app allows users to browse trending news headlines, filter articles by category, and read detailed coverage directly from live APIs.

It is developed using Dio for network requests, Custom Widgets for reusable UI elements, and a modular architecture ensuring clean code separation between UI, logic, and networking layers.

---

📝 About the App

News App simplifies how users stay updated with world events, business, technology, health, science, and entertainment news.

With a seamless and responsive layout, it delivers a smooth news-reading experience with fast loading times and robust dynamic content rendering.

Key highlights of the app:

📰 Live daily news fetching

🗂️ Category-based content filtering

⚡ Fast performance with efficient network handling

🎨 Modern and minimalist User Interface

---

🚀 Features

🏠 Home Screen: Displays top headlines alongside a list of selectable news categories.

🗂️ Category Filtering: Browse dedicated news for categories including Technology, Health, Science, Entertainment, Sports, and Business.

📜 Dynamic News ListView: Asynchronous news feed powered by dynamic builder widgets for optimal scroll performance.

🖼️ Article Cards: Clean layout for news items showcasing thumbnails, headline titles, and short descriptions.

🌐 API Integration: Utilizes Dio to communicate efficiently with RESTful News APIs.

⏳ Loading & Error Handling: User-friendly loading indicators and error states during network fetching.

🧩 Modular Architecture: Clean separation of models, screens, widgets, and API service layers.
